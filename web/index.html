Hank

A Discord bot that replies to your keywords with your own custom responses.

Add Hank to your server

What Hank does

Keyword replies

Pick a word or phrase and what Hank says back whenever someone uses it.

Random replies

Give a keyword several replies and Hank picks one at random each time.

User auto-replies

Have Hank answer everything a certain person says, with an optional cooldown.

Per server

Every server keeps its own list, set up right from Discord with slash commands.

Commands

/hank add keyword response [match]

Reply to a keyword. Add the same keyword again to give Hank more replies to pick from.

/hank remove keyword

Stop replying to a keyword and delete all its replies.

/hank user-add user response [cooldown]

Reply to every message from a user, at most once every cooldown minutes if you set one.

/hank user-remove user

Stop auto-replying to a user.

/hank list

Show this server's keywords and user auto-replies. Only you see the answer.

Commands need the Manage Server permission by default; you can open them up to other roles under Server Settings → Integrations → Hank. Matching ignores case, and {user} in a reply mentions whoever triggered it. match can be whole word (default), anywhere in the message, or whole message only.

Hank is open source on GitHub.
